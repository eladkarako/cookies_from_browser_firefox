# cookies_from_browser_firefox
parallel reads a compatible cookies.sqlite, or a Netscape cookie-file, optionally filters, sorts by host path and cookie name, outputs a Netscape cookie-file (tab separated text) to STDOUT


<hr/>

1. was generated by running `cargo doc --no-deps --document-private-items --release --open` from the project's root.  

2. this `index.html` was added to the doc's root:  

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8" />
  <meta http-equiv="refresh" content="0;url=cookies_from_browser_firefox/index.html" />
  <meta name="viewport" content="width=device-width" />
</head>
<body>
<script>
(()=>{
  self.location.assign("cookies_from_browser_firefox/index.html");
})();
</script>
</body>
</html>
```

3. adding an empty file named `.nojekyll` to ease up rendering (since it is static, and does not uses github's templates).
